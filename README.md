# From Prompt to Agent

عرض ويب تفاعلي كامل الشاشة لمحاضرة أكاديمية العدالة:

**من مخاطبة الآلة إلى تفويضها: من هندسة الأوامر Prompt Engineering إلى هندسة الوكلاء Agent Engineering**

## العرض المعتمد

- 60 شريحة تعليمية بالضبط، باستثناء خريطة المحاور بوصفها واجهة تنقل.
- 5 شرائح افتتاحية، و10 شرائح لكل محور من المحاور الخمسة، و5 شرائح ختامية.
- المحاور: فهم الآلة، هندسة الأوامر، هندسة السياق، سير العمل الذكي، هندسة الوكلاء، والرقابة على التفويض.
- كل محور ينتهي بـWorkshop تطبيقي.

## مبادئ التصميم

- تجربة عرض يسيطر عليها المحاضر، مناسبة للشاشة 16:9 والمشاركة عبر Zoom.
- هوية Dark Executive Tech مع سلطة أكاديمية، وخلفيات طبقية وحركة وظيفية هادئة.
- فكرة رئيسية واحدة لكل شاشة مع Progressive Reveal.
- لا صور روبوتات نمطية ولا زخرفة Cyberpunk مبالغ فيها.

## التقنيات

HTML + SCSS/Sass + Vanilla JavaScript

## التشغيل

افتح `index.html`، أو زر رابط GitHub Pages بعد النشر. يفتح العرض من `src/interactive/opening.html`.

مفاتيح العرض: `Enter` أو السهم الأيسر للتقدم، السهم الأيمن للعودة، `F` لملء الشاشة، و`H` لخريطة المحاور.
