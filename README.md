# من مخاطبة الآلة إلى تفويضها: من هندسة الأوامر إلى هندسة الوكلاء
## د. أحمد عبدالسلام (LEAD ORCHESTRATOR & PROJECT DIRECTOR)
### عرض ويب تفاعلي احترافي (60 شريحة — S01 إلى S60)

هذا المستودع يحتوي على ملفات العرض التفاعلي المسطحة (Flat Files بدون مجلدات فرعية) لسهولة الرفع والتشغيل المباشر عبر **GitHub Pages**.

### هيكل الملفات:
- `index.html`: صفحة العرض الرئيسية.
- `style.css`: التنسيقات البصرية (Dark Executive Tech) مع خطوط Tajawal و Inter.
- `app.js`: المحرك التفاعلي لكافة الشرائح الـ 60 والورش والملاحة.
- ملفات التوثيق المعمارية والعلمية (`00_MASTER_BRIEF.md` إلى `09_NEEDS_USER_REVIEW.md`).

### طريقة التشغيل المباشر:
1. افتح ملف `index.html` في أي متصفح.
2. للتنقل: استخدم الأسهم أو المسافة، `F` لملء الشاشة، `H` للمركز الرئيسي، `M` للمحور الحالي.
