# From Prompt to Agent

مشروع العرض التفاعلي للمحاضرة:

**من مخاطبة الآلة إلى تفويضها**  
**من هندسة الأوامر إلى هندسة الوكلاء**

## الحالة الحالية

يتم تطوير المشروع تدريجيًا وفق المسار:

**مناقشة → اعتماد علمي → Storyboard بصري → Prototype → مراجعة → تنفيذ**

المرحلة الحالية: **Prototype محدود للمحور الأول: كيف تعمل الآلة؟ من التدريب إلى التوليد**.

## مبادئ التصميم

- Presenter-Controlled Interactive Web Presentation
- Desktop / Laptop 16:9 — Zoom Screen Sharing
- Dark Executive Tech
- Motion must explain
- One screen = one main idea
- Progressive Reveal
- لا تُستخدم صور الروبوتات النمطية أو Cyberpunk المبالغ فيه

## التقنيات

HTML + SCSS/Sass + Vanilla JavaScript

> لا يمثل الـPrototype الحالي تنفيذًا نهائيًا للمحاضرة؛ بل اختبارًا للهوية البصرية، العمق، الحركة، التنقل، ووضوح العرض عبر Zoom.
