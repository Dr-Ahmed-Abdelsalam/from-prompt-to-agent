# From Prompt to Agent

عرض ويب تفاعلي كامل الشاشة لمحاضرة أكاديمية العدالة:

**من مخاطبة الآلة إلى تفويضها: من هندسة الأوامر Prompt Engineering إلى هندسة الوكلاء Agent Engineering**

## العرض المعتمد

- 60 مشهدًا مرقّمًا من `S01` إلى `S60`، دون `S61`.
- `S01–S04` افتتاح، `S05–S54` خمسة محاور (10 مشاهد لكل محور)، و`S55–S60` ختام وحوكمة التفويض.
- المحاور: كيف تعمل الآلة؟، هندسة الأوامر، هندسة السياق، سير العمل بالذكاء الاصطناعي، وهندسة الوكلاء.
- الورش في `S14` و`S24` و`S34` و`S44` و`S54` فقط.
- تسمية البنية هي «المحور»، ولا تستخدم «الفصل» أو `Chapter` أو `Module`.

## مبادئ التصميم

- تجربة عرض يسيطر عليها المحاضر، مناسبة للشاشة 16:9 والمشاركة عبر Zoom.
- هوية Dark Executive Tech مع سلطة أكاديمية، وخلفيات طبقية وحركة وظيفية هادئة.
- فكرة رئيسية واحدة لكل شاشة مع Progressive Reveal.
- لا صور روبوتات نمطية ولا زخرفة Cyberpunk مبالغ فيها.

## التقنيات

مصدر العرض: React + Vite + TypeScript + SCSS/Sass في مجلد `app/`.

يحتوي `site/` على نسخة النشر الثابتة المتوافقة مع GitHub Pages، مع الحفاظ على المصدر React لإعادة البناء والتطوير.

## التشغيل

افتح `index.html`، أو زر رابط GitHub Pages بعد النشر. يفتح العرض من `site/`.

مفاتيح العرض: `ArrowRight` أو `Space` أو `PageDown` للتقدم، `ArrowLeft` أو `PageUp` للعودة، `F` لملء الشاشة، `H` للخريطة الرئيسية، `M` لخريطة المحور، و`Escape` لإغلاق الشرح المصغّر.

يمكن فتح أي مشهد مباشرة عبر `#S01` إلى `#S60`، مثل `.../site/#S26`.

لإعادة بناء نسخة النشر من المصدر:

```bash
cd app
npm install
npm run build
```
