# سجل المصادر والتحقق

## حالة السجل

`STATUS: ACTIVE — NO QUANTITATIVE CLAIMS IN CURRENT DECK`

هذا السجل ليس ببليوغرافيا ظاهرية داخل الشرائح. وظيفته حفظ أساس مراجعة المفاهيم، وتحديد ما يلزم أن يتحقق منه حديثًا قبل إدخاله في العرض. لا ينسب العرض رقمًا أو مقارنة أداء أو قدرة منتج أو قاعدة قانونية ما لم يضاف لها مصدر مباشر وتاريخ تحقق.

## قاعدة Freshness Required

يجب وضع الوسم `FRESHNESS_REQUIRED` وإجراء تحقق جديد بتاريخ واضح قبل إدراج أي من الآتي:

- أسماء نماذج أو مزودين أو خصائص منتجات أو حدود نافذة سياق أو تسعير أو ترتيب أداء.
- إحصاءات، نسب، أرقام سوقية، أو نتائج اختبارات مقارنة.
- قوانين أو لوائح أو أحكام أو مواعيد أو سياسات جهة عامة أو خاصة.
- مثال قانوني واقعي، مصدر قضائي، أو ادعاء عن اختصاص أو مسؤولية.
- أي استشهاد مباشر أو اقتباس يُراد عرضه على الشاشة.

## سجل الادعاءات الكمية

لا يحتوي الإصدار الحالي من S01–S60 على ادعاءات كمية أو إحصاءات. لذلك لا يوجد رقم أو نسبة أو ترتيب أداء معتمد للعرض حتى تاريخه.

## بروتوكول إدخال مصدر جديد

1. حدّد الشريحة/الشرائح المتأثرة بصيغة `Sxx`.
2. أضف المصدر الأولي أو الرسمي ورابطه وتاريخ الاطلاع.
3. اذكر الادعاء المحدد الذي يدعمه المصدر، لا موضوعًا عامًا فقط.
4. قيّم ما إذا كان زمنيًا أو قانونيًا أو مرتبطًا بمنتج؛ عندها يبقى `FRESHNESS_REQUIRED` حتى اعتماد المراجعة.
5. لا تُحوّل المصدر إلى فقرة على الشاشة؛ يظل النص الظاهر موجزًا ويُذكر المصدر في ملاحظة المحاضر أو المادة المرافقة عند الحاجة.

## ملاحظة قانونية

هذا العرض لا يعتمد — حتى الآن — مصادر قانونية موضوعية أو أحكامًا أو بيانات قضايا. أي إدخال لاحق من هذا النوع يحتاج سجل مصدر منفصل ومراجعة قانونية مختصة، ولا يكفي هذا السجل التقني.
