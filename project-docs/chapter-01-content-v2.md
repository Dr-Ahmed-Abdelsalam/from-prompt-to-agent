# المحور الأول — كيف تعمل الآلة؟ من التدريب إلى التوليد

هذه هي النسخة المبسطة المعتمدة للمراجعة البصرية. الهدف هو تقليل المصطلحات الظاهرة على الشاشة، مع الحفاظ على الفكرة العلمية الأساسية وترك التفاصيل للشرح الشفهي أو المشاهد الفرعية.

## 00 — الغلاف
**يظهر:** من مخاطبة الآلة إلى تفويضها / من هندسة الأوامر إلى هندسة الوكلاء / دكتور أحمد عبدالسلام / الشعار.

## 01 — محاور الندوة
خمسة محاور فقط مع شريط «الرقابة على التفويض».

## 02 — افتتاح المحور الأول
**كيف تعمل الآلة؟**
من التدريب إلى التوليد.
بصريًا: مدخلات → نواة غامضة → مخرج.

## 03 — رحلة داخل الآلة
ست محطات فقط:
المفاهيم → البيانات → التدريب → التوليد → الحدود → الإنسان.

## 04 — AI ليس ChatGPT
لوحة تفاعلية مركزها AI وحولها: Classification / Prediction / Detection / Generation / Assistant / Agent / ChatGPT.
النقر يفتح مشهدًا شارحًا صغيرًا، والسحب يعيد ترتيب العلاقة.

## 05 — أين يقع LLM؟
Artificial Intelligence → Machine Learning → Deep Learning → Foundation Models → LLM.
مع مجال Generative AI منفصل جزئيًا.
الرسالة: Foundation Model ≠ LLM، وGenerative AI ≠ LLM.

## 06 — من الصورة والكلمة إلى البيانات
مساران فقط:
- الصورة: Pixels → Values → Patterns
- النص: Tokens → IDs → Representation
ثم يلتقيان في: تمثيل رقمي قابل للمعالجة.

## 07 — من يبني المنظومة؟
Data Engineer / Data Analyst / Data Scientist / ML Engineer / AI Engineer.
يعرض دور كل منهم بجملة واحدة فقط.

## 08 — كيف يتعلم النموذج؟
Data → Prediction → Error → Adjust Weights → Repeat.
الرسالة: التدريب يغيّر الأوزان، والنموذج ليس قاعدة بيانات مستندات.

## 09 — كيف تتكوّن الإجابة؟
Prompt → Context → Model → احتمالات → Next Token.
الرسالة: التوليد يبني المخرج تدريجيًا، والسؤال العادي لا يعيد التدريب.

## 10 — ماذا يرى النموذج أثناء المهمة؟
Context Window يتضمن: Instructions / Prompt / Conversation / Documents / Retrieved Knowledge / Tool Results.
الرسالتان: Context ≠ Training، وFile Upload ≠ Fine-tuning.

## 11 — الطلاقة ليست دليلًا على الصحة
مرجع يبدو مقنعًا ثم يفشل التحقق منه.
Fluency ≠ Accuracy / Generated ≠ Verified.

## 12 — كيف يتغير العمل؟
JOB تتوزع إلى: Human / Human + AI / AI-Assisted / Delegatable / Human Review.
الرسالة: AI يعيد تشكيل المهام أولًا، ثم المهارات، ثم الوظائف.

## 13 — ليست العملية نفسها
Training / Fine-tuning / Prompting / Context / RAG / Tool Use.
كل مفهوم بجملة واحدة، مع مشهد فرعي عند الضغط.
الرسالة: إعطاء الآلة معلومات لا يعني أنك أعدت تدريبها.

## 14 — ماذا فهمنا عن الآلة؟
- البيانات تغذي المنظومة.
- التدريب يشكّل النموذج.
- السياق يحدد ما هو متاح الآن.
- التوليد يبني المخرج تدريجيًا.
- التحقق خطوة مستقلة.

## 15 — Workshop: هل دربت الآلة فعلًا؟
A: رفع أحكام للتحليل → Context.
B: Dataset لتدريب إضافي → Fine-tuning.
C: تعليمات تفصيلية → Prompting.
D: استرجاع أحكام وإضافتها للسياق → RAG.
E: Search أو Calculator → Tool Use.

**الرسالة الختامية:** إعطاء الآلة معلومات ≠ تدريبها.
