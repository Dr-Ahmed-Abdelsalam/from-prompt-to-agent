# قاموس المصطلحات المعتمد

## قاعدة العرض

تظهر الإنجليزية أولًا عند موضعها التعليمي، ثم تتحول إلى العربية في الموضع نفسه. العربية أدناه هي الصياغة النهائية المستقرة. لا تُترجم الجمل العادية كلمة بكلمة، ولا يُنشأ مصطلح جديد داخل شريحة من دون مراجعة هذا القاموس.

| English | العربية المعتمدة | ضبط الاستعمال |
|---|---|---|
| Artificial Intelligence (AI) | الذكاء الاصطناعي | مظلة واسعة لتقنيات تؤدي مهامًا تتطلب عادةً قدرة معرفية. لا يساوي ChatGPT أو نموذجًا بعينه. |
| Algorithm | خوارزمية | خطوات أو قواعد قابلة للتنفيذ؛ ليست مرادفًا للذكاء الاصطناعي. |
| Machine Learning (ML) | تعلّم الآلة | تعلّم أنماط من بيانات وفق هدف/إشارة تدريب. |
| Deep Learning | التعلّم العميق | فرع من تعلّم الآلة يعتمد شبكات عصبية متعددة الطبقات. |
| Foundation Model | نموذج أساس | نموذج واسع قابل للتكييف لمهام لاحقة؛ لا يلزم أن يكون لغويًا فقط. |
| Large Language Model (LLM) | نموذج لغوي كبير | نموذج مخصص لمعالجة/توليد اللغة على نطاق واسع. |
| Generative AI | الذكاء الاصطناعي التوليدي | أنظمة تُنتج محتوى مثل النص أو الصورة أو الصوت. |
| Data | البيانات | تمثيلات قابلة للمعالجة؛ قد تكون منظمة أو غير منظمة. |
| Structured Data | بيانات منظمة | بيانات ذات حقول أو بنية معلنة، مثل جدول أو سجل. |
| Unstructured Data | بيانات غير منظمة | محتوى لا يأتي في حقول ثابتة، مثل وثيقة أو تسجيل. |
| Token | وحدة رمزية | جزء يعالجه النموذج من النص؛ لا يساوي بالضرورة كلمة أو حرفًا. |
| Representation | تمثيل رقمي | صيغة عددية/حسابية يستعملها النظام لمعالجة المدخلات. |
| Embedding | تمثيل متجهي | تمثيل رقمي على هيئة متجه يساعد في قياس صلة أو تشابه تقريبي. |
| Contextual Representation | تمثيل سياقي | تمثيل يتغير وفق الكلمات أو العناصر المحيطة. |
| Training | التدريب | تحديث معاملات النموذج من بيانات وفق هدف تدريب. |
| Inference | الاستدلال | تشغيل نموذج مدرّب لإنتاج مخرج من مدخلات محددة. |
| Parameter | معامل | قيمة قابلة للتعديل داخل النموذج. |
| Weight | وزن | معامل يؤثر في قوة علاقة حسابية داخل النموذج. |
| Prompt | أمر | تعليمات ومدخل يوجهان المهمة؛ وقد يضم سياقًا أو أمثلة. |
| Prompt Engineering | هندسة الأوامر | تصميم بنية التعليمات والمخرج ومعيار الجودة لتقليل مساحة التخمين. |
| Context | السياق | المعلومات المتاحة للنظام لحظة إنجاز المهمة. |
| Context Window | نافذة السياق | السعة التي يمكن للنموذج التعامل معها من سياق في طلب/تشغيل محدد. |
| Context Engineering | هندسة السياق | اختيار وتنظيم وتحديث المعلومات الملائمة التي يحتاجها النظام. |
| Retrieval | الاسترجاع | جلب مادة محتملة الصلة من مصدر خارجي. |
| Retrieval-Augmented Generation (RAG) | التوليد المعزّز بالاسترجاع | استرجاع مادة ملائمة ثم وضعها في السياق قبل التوليد؛ لا يساوي التحقق. |
| Fine-tuning | الضبط الدقيق | تدريب إضافي موجّه على بيانات أو نمط مطلوب. |
| Hallucination | هلوسة | مخرج غير مسند أو غير صحيح أو غير قابل للتحقق؛ لا يدل على قصد. |
| Verification | التحقق | فحص ادعاء أو مخرج في مقابل مصدر أو معيار محدد. |
| Evaluation | التقييم | قياس أو حكم منظم على جودة مخرج أو نظام وفق معايير معلنة. |
| Tool Use | استخدام الأدوات | استدعاء خدمة أو برنامج أو مصدر خارجي لإنجاز فعل أو جلب نتيجة. |
| Workflow | سير العمل | تسلسل من خطوات وقرارات ومخرجات وحالات قابلة للتكرار. |
| State | حالة العمل | وضع منظم يبيّن أين وصلت العملية وما الذي يسمح به بعدها. |
| Intermediate Artifact | مخرج وسيط | ناتج مرحلي قابل للفحص وإعادة الاستخدام، مثل جدول أو قائمة تحقق. |
| Human Gate | بوابة الموافقة البشرية | نقطة توقف تتطلب قرار شخص مخوّل قبل متابعة العملية. |
| Agent | وكيل | نظام موجّه بهدف يختار أفعالًا تالية ضمن أدوات وحدود وحالة/ملاحظات. |
| Agent Engineering | هندسة الوكلاء | تصميم أهداف الوكيل وتعليماته وأدواته وحالته وحدوده ورقابته. |
| Planning | التخطيط | ترتيب أفعال ممكنة لخدمة هدف وفق المعطيات المتاحة. |
| Action | فعل | خطوة ينفذها النظام، مثل استدعاء أداة أو إنشاء مسودة. |
| Observation | ملاحظة | نتيجة أو حالة يستعملها النظام لتقرير ما يلي؛ ليست إدراكًا واعيًا. |
| Memory | الذاكرة | بيانات يعاد استخدامها عبر خطوات/جلسات بحسب تصميم النظام؛ يلزم بيان نوعها. |
| Autonomy | الاستقلالية | مدى قدرة النظام على الاختيار والتنفيذ داخل حدود مفروضة. |
| Permission | صلاحية | فعل أو مورد يسمح للنظام باستخدامه. |
| Least Privilege | أقل صلاحية لازمة | منح الحد الأدنى من الصلاحيات اللازمة للمهمة. |
| Guardrails | ضوابط الحماية | قواعد أو اختبارات أو قيود تمنع/توجه أفعالًا أو مخرجات محددة. |
| Human Oversight | الرقابة البشرية | متابعة بشرية ذات سلطة للضبط أو الاعتماد أو الإيقاف أو التصعيد. |
| Audit Log | سجل التدقيق | أثر زمني منظم للأفعال والقرارات والنتائج؛ لا يثبت وحده سلامة قانونية. |
| Auditability | قابلية التدقيق | إمكان تتبع وفحص ما حدث في النظام على نحو ذي معنى. |
| Governance | حوكمة التفويض | قواعد توزيع الصلاحيات والرقابة والتقييم والمساءلة في التفويض. |
| Stop Condition | شرط التوقف | واقعة أو قاعدة توقف التنفيذ أو تحولّه إلى التصعيد البشري. |

## ألفاظ يجب تجنبها

| اللفظ | البديل أو سبب التجنب |
|---|---|
| «النموذج يفهم مثل الإنسان» | «يبني تمثيلات ويولد مخرجات اعتمادًا على أنماط ومدخلات». |
| «الوكيل مستقل تمامًا» | «استقلاليته محدودة بالصلاحيات والضوابط وشروط التوقف». |
| «RAG يضمن الحقيقة» | «RAG يزوّد النظام بمادة مسترجعة تحتاج تقييمًا وتحققًا». |
| «التدريب = رفع ملف» | «رفع الملف قد يضيف سياقًا أو مادة مسترجعة، ولا يعني تدريبًا». |
| «الذكاء الاصطناعي اتخذ قرارًا» | «أنتج توصية/مخرجًا أو نفّذ فعلًا داخل قواعد محددة». |
