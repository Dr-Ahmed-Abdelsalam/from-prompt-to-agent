# من مخاطبة الآلة إلى تفويضها

عرض تفاعلي كامل الشاشة لمحاضرة أكاديمية العدالة:

> من هندسة الأوامر إلى هندسة الوكلاء

## البنية

- `index.html` — الافتتاحية.
- `hub.html` — خريطة المحاضرة والمحاور الخمسة.
- `chapter-1.html` إلى `chapter-5.html` — فصول العرض التفاعلية.
- `assets/js/content.js` — محتوى الشرائح، ويمكن تعديله دون المساس بنظام العرض.
- `assets/scss/style.scss` — مصدر نظام التصميم.
- `assets/css/style.css` — النسخة التي يقرأها المتصفح.

## طريقة العرض

- `Enter` أو `←`: التالي أو إظهار العنصر التالي.
- `→`: السابق.
- النقر في يمين الشاشة: التالي؛ وفي يسارها: السابق.
- سحب أفقي على شاشة اللمس: للتنقل.
- `F`: ملء الشاشة.
- `H`: العودة إلى خريطة المحاضرة.

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا على GitHub ثم ارفع محتويات هذا المجلد كما هي.
2. من **Settings → Pages** اختر النشر من فرع `main` ومن مجلد `/ (root)`.
3. احفظ الإعدادات، ثم افتح رابط GitHub Pages الذي يظهر لك.

لا توجد تبعيات أو عملية بناء مطلوبة للنشر؛ يكفي رفع الملفات. عند تعديل `assets/scss/style.scss` ينبغي تحديث `assets/css/style.css` بالنسخة المترجمة قبل الرفع.
