# 05 — قواعد الحركة والانتقال

## المبدأ الحاكم

**الحركة تشرح، ولا تزيّن.**

كل حركة في العرض يجب أن تجيب عن سؤال: ما العلاقة أو التغير الذي يراه الحضور بسببها؟ إذا لم تضف الحركة معنى، تُحذف. المحاضر هو قائد التجربة؛ فلا توجد حركة تنقل الشريحة تلقائيًا، ولا سلسلة ضغطات لازمة لاكتشاف بنيتها الأساسية.

## خط الزمن داخل المشهد

عند دخول أي شريحة:

1. تظهر البنية الأساسية للمشهد فورًا أو خلال أقل من 500ms.
2. تنفذ الحركة التفسيرية القصيرة خلال 0.8–2.5 ثانية بحسب الفكرة.
3. يستقر كل المحتوى الضروري للشرح ويبقى ظاهرًا.
4. تستمر الخلفية الحية وتحول المصطلحات الثنائي اللغة بهدوء ما دامت الشريحة مفتوحة.
5. لا يغادر المشهد إلا بأمر المحاضر.

## أفعال الحركة المعتمدة

| الفعل | ما يشرحه | مثال |
|---|---|---|
| Flow — تدفّق | انتقال معلومة أو مادة بين عناصر | مستندات تتدفق نحو نافذة السياق |
| Dive — غوص | الانتقال من المفهوم العام إلى بنية داخلية | الغوص من نص إلى Tokens |
| Zoom — تكبير | إظهار موضع أو طبقة ذات صلة | تكبير جزء من Workflow لتوضيح قرار |
| Decompose — تفكيك | تحليل الكل إلى عناصره | Prompt يتفكك إلى هدف وسياق وقيود |
| Converge — تقارب | اجتماع مدخلات في نتيجة أو نموذج | بيانات تتقارب لتكوين تمثيل |
| Loop — حلقة | تكرار واعٍ مع تغذية راجعة | توقع → خطأ → تعديل أوزان → تكرار |
| Feedback — تغذية راجعة | أثر نتيجة على قرار لاحق | مراجعة بشرية تعود إلى الوكيل |
| Boundary — حد | صلاحية أو قيد أو منع | أداة تتوقف عند حدّ التفويض |
| Focus — تركيز | عزل جزء مؤقتًا من المشهد | عقدة من مخطط الوكيل تبرز للشرح |
| Pull-back — انسحاب بصري | العودة من تفصيل إلى الصورة الكلية | إغلاق Mini Explainer والعودة للمخطط |
| Transform — تحوّل | انتقال معنى أو صيغة | المصطلح الإنجليزي يتحول إلى العربية |

## الحركة الخلفية

- الموجة الزرقاء تسير بتباطؤ دائم؛ لا تزيد سرعتها عند الانتقال العادي.
- الموجة البرتقالية تظهر أو تقوى قليلًا قرب مشاهد القرار، التفويض، والحماية.
- النقاط والمسارات التقنية نبضها بطيء ومحدود؛ لا تومض ولا تتحرك عشوائيًا.
- الخلفية تخفت عند كثافة المعلومات أو عند فتح شرح مصغّر.
- لا يسمح بحركة Parallax عشوائية، أو جزيئات تطلب الانتباه باستمرار.

## انتقالات المشاهد

الانتقال الافتراضي بين الشرائح:

```text
Fade + very subtle scale
```

- دخول: عتامة من 0 إلى 1 مع مقياس من 0.992 إلى 1.
- خروج: عتامة تخف برفق؛ من دون دفع أفقي للمشهد.
- المدة المستهدفة: 350–500ms.
- الانتقالات الكبرى فقط (S04، S14→S15، S24→S25، S34→S35، S44→S45، S54→S55) قد تستخدم تحولًا أعمق: إعادة ترتيب المسار الضوئي أو غوص/انسحاب بصري مرتبط بالمفهوم.

ممنوع: Side Slide، دوران كبير، Flying Cards، Bounce، قلبات كبيرة، أو أي انتقال يجعل العرض يبدو كقالب عروض تقليدي.

## حركة المصطلحات الثنائية

تطبق على أسماء المفاهيم والعناصر التقنية، لا على الجمل العربية العادية:

1. يظهر المصطلح الإنجليزي 4–6 ثوانٍ.
2. ينتقل بـSoft Fade أو Blur → Clear أو Micro Vertical Morph خلال 300–500ms.
3. تظهر العربية في المكان نفسه وبالعرض/الارتفاع المحجوزين نفسيهما.
4. يتكرر التبادل بتوقيت متدرج إن وُجدت مصطلحات متعددة في المشهد.

الممنوع: Typewriter متكرر، Glitch قوي، Side Slide، Rotation، أو Flip كبير. يوقف التبادل مؤقتًا عند Focus أو Drag أو Mini Explainer، ثم يستأنف عند انتهاء التفاعل من غير أن يغيّر موضع العنصر أو حالة السحب.

## ظهور المحتوى داخل المشهد

- لا تُخفى مكونات المشهد الأساسية خلف ضغطات متلاحقة.
- يمكن أن يظهر العنوان أولًا ثم الرسم خلال جزء من الثانية، ثم العلامات بترتيب يعكس العلاقة.
- عند وجود عملية: تظهر المراحل بترتيب سيرها، لا بترتيب زخرفي.
- عند وجود مقارنة: يستقر الطرفان أولًا ثم يظهر الفرق المضيء أو خط الفصل.
- عند وجود خطر أو قيد: يظهر الحد قبل نتيجة تجاوزه، كي تكون الحركة تفسيرًا سببيًا.

## قواعد التفاعل الحركي

التفاعل يُستخدم في المشاهد التي يحتاج معناها إلى تجربة، لا في كل الشاشات.

- عناصر السحب تتجاوب بـMicro Lift وتوهج محدود، مع Cursor: grab؛ ولا تستخدم نصًا ظاهرًا يشرح السحب.
- عند السحب، تتثبت الاتصالات والعلامات المرتبطة بالعقدة أو تعاد رسمها بسلاسة؛ ولا يحدث انتقال للشريحة.
- عند الإفلات، يستقر العنصر دون Bounce أو ارتداد مبالغ.
- عند إعادة ترتيب عناصر Prompt أو Workflow، يتحرك التركيب الناتج ليعكس القرار، لا لمجرد عرض الحركة.
- عند سحب صلاحية من وكيل، ينطفئ مسار الأداة ويظهر حد التفويض البرتقالي؛ لا تختفي الشبكة بالكامل.
- يحتفظ العرض بحالة التفاعل طوال الجلسة: الموضع، الترتيب، العقدة المركزة، ونطاق الصلاحيات لا تعاد تلقائيًا.

## Mini Explainer

يفتح الشرح المصغر بوصفه طبقة بصرية، لا كنافذة نصية. الخلفية تهدأ، والمخطط يقترب من المفهوم المطلوب:

- Classification: Objects → Categories.
- Generation: Prompt → Model → Generated Output.
- RAG: Question → Retrieve → Relevant Sources → Context → Model.
- Agent: Goal → Plan → Tool → Action → Observation → Next Action.

يغلق بـESC أو أيقونة عودة، مع Pull-back هادئ يعيد المشهد إلى حالته السابقة تمامًا.

## الحركة الممنوعة

- Flying cards أو طيران عناصر بلا وظيفة.
- تحريك نصوص كبرى باستمرار لجذب الانتباه.
- مؤثرات نبضية قوية أو متكررة.
- جزيئات كثيفة، أسطر Matrix، أو مؤثرات Cyberpunk/Hacker.
- Parallax عشوائي أو دوران واسع.
- حركة جانبية بين الشرائح.
- حركات تمنع قراءة الشاشة عبر Zoom أو تحدث بعد استقرار المشهد بلا وظيفة تعليمية.

## معيار المراجعة قبل اعتماد أي حركة

لا تعتمد حركة في `Sxx` إلا إذا تحققت الأسئلة الأربعة:

1. ما الفكرة التي تشرحها؟
2. هل تبقى القراءة مريحة على Zoom؟
3. هل تستقر قبل بدء الشرح الفعلي؟
4. هل تحتفظ بحالة تفاعل المحاضر ولا تقوده إلى انتقال غير مقصود؟
