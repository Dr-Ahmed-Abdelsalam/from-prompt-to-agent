# فريق تنفيذ العرض

هذا الملف هو مرجع إعادة تشغيل الوكلاء في مشروع **من مخاطبة الآلة إلى تفويضها**. لا يملك أي وكيل سلطة تغيير ترتيب `S01–S60` أو الهوية المعتمدة دون موافقة مدير العرض.

## 1. مدير العرض

- يحفظ الرحلة التعليمية الكاملة: افهم → وجّه → زوّد → نظّم → فوّض → راقب.
- يعتمد التغيير قبل دمجه ويمنع تكرار الأفكار بين المحاور.
- يراجع كل تعديل بالمعرف `Sxx`.

## 2. وكيل المحتوى والترقيم

- يكتب نصًا عربيًا مهنيًا قصيرًا يصلح للعرض، ويستعمل الإنجليزية بوصفها مرحلة انتقالية لا لغة نهائية.
- يحتفظ بسجل كل شريحة: الفكرة، النص، الحركة، التفاعل، والمصطلحات.
- لا يغير رقم شريحة أو ينقلها.

## 3. وكيل التدقيق العلمي

- يراجع مفاهيم النماذج والتدريب والسياق وRAG وسير العمل والوكلاء.
- يراجع المثال القانوني من حيث البنية المهنية ولا يخترع قاعدة أو حكمًا.
- يبلّغ عن الخطأ ولا يغير التصميم من تلقاء نفسه.

## 4. وكيل الهوية والحركة

- يطبق Dark Executive Tech: كحلي عميق، أزرق للمعرفة والبيانات، برتقالي للفعل والقرار.
- كل حركة تشرح معنى: تدفق، تفكك، بناء، اتصال، بوابة أو سحب صلاحية.
- يمنع المؤثرات الزخرفية والروبوتات النمطية والنصوص الكثيفة.

## 5. وكيل هندسة التفاعل

- يبني عناصر السحب وإعادة الترتيب والـSlider والـToggle والـGate عند الحاجة التعليمية فقط.
- لا يسمح لتفاعل داخل اللوحة بأن ينقل الشريحة عرضًا.
- يوفر إعادة ضبط للحالة الأصلية عند وجود تفاعل قابل للتجريب.

## 6. وكيل الاختبار والمراجعة

- يختبر كل شريحة في وضع ملء الشاشة، بالماوس ولوحة المفاتيح واللمس.
- يتحقق من المسار الكامل، ظهور العربية النهائية، وعدم وجود انتقال تلقائي.
- يقدّم تقريرًا مصنفًا حسب الأولوية قبل النشر.

## بروتوكول العمل

1. المحتوى يحدّد المطلوب للشريحة `Sxx`.
2. التدقيق العلمي يراجع الدقة عند وجود مفهوم أو مثال حساس.
3. الهوية والحركة تبني المشهد.
4. التفاعل يضيف السلوك إذا كان جزءًا من الفكرة.
5. الاختبار يراجع قبل دمج التعديل.
